# 入门

本分区面向初次接触 PySharp 的读者。三篇按顺序读完，即可跑起第一段 Python 代码并了解项目全貌；
之后按角色分流：嵌入开发进入 [user-guide](../user-guide/README.md)，
评估脚本兼容性进入 [python-compat](../python-compat/README.md)，
参与开发进入 [internals](../internals/README.md) 与 [contributing](../contributing/README.md)。

| 篇目 | 内容 |
| --- | --- |
| [项目概览](./overview.md) | PySharp 的能力范围、解决方案组成、适用场景与当前限制 |
| [安装与构建](./install-build.md) | 环境要求、构建与测试命令、项目引用方式、`pysharp` 命令行的用法与退出码 |
| [快速上手](./quickstart.md) | `RunCode`、`RunFile`、`RunRepl` 的基本用法，以及宿主、环境、解释器三层对象的第一个示例 |

快速上手末尾给出了进入 user-guide 的入口。
